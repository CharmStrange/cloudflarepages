CloudFlare 와 GitHub 조합으로 이렇게나 쉽게, 무료로 개인 웹 사이트 구축이 가능해졌다.

다른 사람들 다 이렇게 웹 페이지 만들고 있을 때 나만 이렇게나 늦게 시작하다니...

사실 개인 웹 페이지는 한 4년 전부터 라즈베리파이로 만드려 했으나 그땐 기기 값하고 랜 기기 포팅 뭐 이런 직접 하나하나 다 공부해보고 만져야 되는 시대였기에 정작 사놓기만 하고 써먹질 못했다.

그런데 불과 4년만에 이렇게 AI 딸깍으로 거의 1분 - 2분만에 이런 사이트 구축을 하다니 참 세상 알 수 없다.
